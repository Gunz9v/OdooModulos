# Documentos y Boletas de Empleados (compatibilidad)

**Odoo:** 18.0 · **Version del modulo:** 18.0.1.0.0 · **Categoria:** Recursos Humanos

## Descripcion

Modulo puente de compatibilidad entre Legajos de Empleados y SmartDoc Laboral; no constituye una aplicacion independiente.

## Funcionalidades principales

Modulo puente de compatibilidad entre Legajos de Empleados y SmartDoc Laboral; no constituye una aplicacion independiente.

Para conocer los modelos, vistas, reglas de acceso y flujos implementados, consulta los directorios `models/`, `views/`, `security/` y el archivo `__manifest__.py` cuando correspondan.

## Dependencias

- `employee_legajo_documents`
- `smart_labor_documents`

## Instalacion

1. Coloca este modulo y sus dependencias en el directorio de addons de Odoo 18.
2. Actualiza la lista de aplicaciones.
3. Instala el modulo desde Aplicaciones, comprobando previamente sus dependencias.
4. Configura los permisos y parametros requeridos para tu entorno.
