# Peru SUNAT Purchase Proposal

**Odoo:** 18.0 · **Version del modulo:** 18.0.1.0.0 · **Categoria:** Contabilidad / SUNAT

## Descripcion

Importacion de propuestas RCE, comparacion con compras registradas y asistencia para generar facturas faltantes.

## Funcionalidades principales

## Dependencias

- `account`
- `l10n_pe`

## Instalacion

1. Coloca este modulo y sus dependencias en el directorio de addons de Odoo 18.
2. Actualiza la lista de aplicaciones.
3. Instala el modulo desde Aplicaciones, comprobando previamente sus dependencias.
4. Configura los permisos y parametros requeridos para tu entorno.
